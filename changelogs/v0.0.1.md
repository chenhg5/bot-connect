## v0.0.1 — 2026-10-09

First public preview. One IM bot per person: you (and your colleagues) talk to the bot in Feishu; it
answers directly or hands work to coding-agent sessions (Claude Code / Codex) and reports back.

**Status: preview.** Config keys and behaviour may still change. macOS and Linux only.

### Highlights

- **Pluggable brain, no model loop of its own.** The front agent is Claude Code, Codex or any CLI agent,
  driven through an `Adapter` interface. bot-connect injects its tools (MCP, or the `bot-connect tool` CLI),
  a role prompt (your persona + a fixed protocol) and live context each turn.
- **Workers are sessions.** One queue per agent session; sessions are read from the agents' own stores
  (including ones used in the terminal/IDE) but reachable **only** through a worker's allowlist
  (`session_id`, `sessions`, `dir_sessions`). Tasks wait while a session is in use locally.
- **Access layer.** Per-chat conversations, coalescing of rapid messages, priority
  (owner > task report > visitor) and a global concurrency cap.
- **Roles and isolation.** owner / admin / member / visitor; `per_user` workers give each member their own
  instance (own session + own directory or git worktree); `isolation = "per_user"` for group chats.
- **Permissions as one vocabulary.** `access = readonly | workspace | full`, `read_dirs`, `write_dirs`,
  `deny_read`, translated to Claude Code (permission mode + OS sandbox + deny rules) and Codex
  (permission profiles). Brains and shared workers run isolated from the owner's own agent setup
  (no `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, plugins or MCP connectors).
- **Feishu** via the SDK, via an app held by lark-cli, or by QR onboarding (`bot-connect feishu setup`).
  Owner defaults to the Feishu app's owner.
- **Multi-bot** in one process (`[[bots]]`), sharing one worker pool.
- **Audit log** of every message (with resolved sender), turn, tool call and task:
  `<data_dir>/audit/YYYY-MM-DD.jsonl`.
- **INSTALL.md** written for AI agents to install and configure the bot for a user.

### Install

```bash
go install github.com/chenhg5/bot-connect/cmd/bot-connect@v0.0.1
```

or download a binary below, then follow [INSTALL.md](https://github.com/chenhg5/bot-connect/blob/v0.0.1/INSTALL.md).

### Known limitations

- No approval round-trip yet: actions outside a worker's sandbox are refused, not asked for.
- Claude subscription login (no API key) for isolated brains is untested.
- Feishu is the only IM channel.
