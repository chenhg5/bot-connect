## v0.0.2 — 2026-10-10

Windows support, one-line installers, npm package, and a fix for cancelled tasks leaving processes behind.

**Status: preview.**

### Highlights

- **Windows** (amd64 / arm64): release zips, `install.ps1`, npm. Agent process trees are stopped with
  `taskkill /T`. Claude Code has no OS sandbox on Windows, so `confine` is not enforced for Claude workers
  there (a warning is logged); Codex permission profiles use Codex's own Windows sandbox.
- **Install in one line:**
  - macOS / Linux: `curl -fsSL https://raw.githubusercontent.com/chenhg5/bot-connect/main/install.sh | sh`
  - Windows: `irm https://raw.githubusercontent.com/chenhg5/bot-connect/main/install.ps1 | iex`
  - npm: `npm install -g bot-connect`

  All verify the archive against `checksums.txt`.
- **`bot-connect version`**, also correct for `go install …@vX.Y.Z` builds.
- **MIT license.**

### Fixes

- Cancelling a task now stops every process the agent started. Previously a shell that the agent had put
  in its own process group (Claude Code does this for its Bash tool) kept running after `/cancel` or a
  timeout.
- Isolated Codex runs share the owner's login by link; if Codex refreshes the login by replacing the file,
  the newer login is copied back to the owner's `~/.codex`, so the owner is never left with a revoked token.
