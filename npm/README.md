# bot-connect

One IM bot per person. Chat with your bot in Feishu; it answers directly or hands work to coding-agent
sessions (Claude Code / Codex) and reports back. Colleagues can talk to it too, with restricted rights.

```bash
npm install -g bot-connect
bot-connect version
```

This package downloads the matching binary from
[GitHub Releases](https://github.com/chenhg5/bot-connect/releases) (macOS / Linux, x64 / arm64) and
verifies its checksum.

Setup: [INSTALL.md](https://github.com/chenhg5/bot-connect/blob/main/INSTALL.md) — written so an AI agent
can configure the bot for you. License: MIT.
